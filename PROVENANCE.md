## How to read a result

For any project, first identify the **source and version**, the **actual observation or executed action**, and the **verification that was performed**. Then check what remained untested. A hash checks bytes; it does not identify an external owner. A native test can establish a bounded program behavior; it does not establish a deployment or a real-world outcome. A documented proposal is not an executing worker.

This page is a navigational audit, not a replacement for the experiment's own ledger. Older descriptions, including claims corrected by newer source publication, remain in the [October 13 historical provenance snapshot](PROVENANCE_2026-10-13.md) and Git history.
