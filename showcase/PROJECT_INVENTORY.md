[← Profile](../README.md) · [Showcase](README.md) · [Every tracked source path](SOURCE_INDEX.md) · [Writing](../writing/README.md)

> **Purpose.** A recoverable index of every distinct project family found in the connected GitHub repositories, plus separately labeled historical/local projects previously discussed. An individual file, experiment, prototype, and commercial product are not interchangeable. **This is an inventory, not a declaration that every project is finished.**

## Source and status key

- **Public code** — directly accessible source or artifact in `huntingthereferent/language-network` or the profile repository.
- **Public report** — documented history or design whose runnable underlying implementation may be incomplete or elsewhere.
- **Local / historical** — previously reported local work; the full current source was not verified in the connected default-branch tree.
- **Private repository** — present in a separately connected private GitHub account; implementation is **not** linked from this public showcase.
- **Draft / unmerged** — proposed branch or pull request, not integrated into `main`.
- **Simulated / modeled** — digital witness, not physical realization or production shipment.
- **Planned** — defined objective or requirement, not evidence of completed delivery.

**Provenance:** Work was developed using AI-assisted vibe coding, while the human side directed the questions, origins, choices, corrections and interpretation. Notation, code generation, tests and reports do not by themselves establish independent correctness.

## 09 / Source manifest and open limits

The [source-path index](SOURCE_INDEX.md) lists **all tracked default-branch paths** retrieved from the connected public `language-network` repository for this audit. It is a directory snapshot, not an assertion that each file is a standalone product.

Other connected private repositories were inspected only to establish their high-level identity; their private code is not reproduced here. Earlier local experiments and historical archives may not be fully represented on the current default branch.

The catalog does **not** imply: universal mathematics inferred from the experiments, independent replication of all local experiments, an autonomous unrestricted building agent, physical machinery, verified ARC prize/leaderboard results, paid contracts, or publication of private source.
