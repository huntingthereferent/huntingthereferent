## What counts when the work moves

I want the **source revision**, **native input or observation**, **permitted movement**, **returned evidence**, **independent check when available**, and **counterexample or unresolved edge**. If a later run contradicts an earlier one, preserve both with their source identities and correct the conclusion. A passing test is never permission to enlarge its scope.

The table separates evidence types deliberately:

- **Source present** means the implementation or test exists at the linked revision; it does not claim the code ran today.
- **Workflow succeeded** means GitHub recorded a successful run for its exact head revision; it does not replace native observation or independent review.
- **Native result** requires the original environment's returned state and admissible witness, not a drawing, predicted trace, or a similar simulator.
- **Open** means the evidence required for a larger conclusion is absent or not inspected. It is not silently promoted to success.

A reader can challenge a row by following the pinned source and the original run or PR. For newer work, return to [the live research repository](https://github.com/huntingthereferent/autobots-assemble), compare its current head against the revision above, and inspect the new native record before revising the claim.
